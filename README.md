# Bitstreaming Radio Panel

**Bitstreaming Radio Panel** es una suite de gestión de radios web, basada en [AzuraCast](https://github.com/AzuraCast/AzuraCast) (software libre bajo licencia AGPL-3.0).

Es un fork personalizado para Bitstreaming: mantiene toda la potencia de AzuraCast (AutoDJ, streaming, podcasts, webhooks, API) con marca, colores y funciones propias.

## Características

- Gestión completa de estaciones de radio (AutoDJ, Liquidsoap, Icecast)
- Reproductor web público con marca propia
- Podcasts, on-demand, solicitudes de canciones
- Webhooks (Discord, Telegram, Slack, etc.)
- API REST documentada
- Despliegue con Docker + Ansible
